# Commercial Lines Client Folder Template

Copy this entire folder for each new commercial client. Rename to `[Business Name]`.

## Folder Guide

| Folder | What goes here |
|---|---|
| General-Liability | Dec pages, policy docs, endorsements |
| Commercial-Auto | Dec pages, policy docs, MVRs, schedules |
| Workers-Comp | Dec pages, policy docs, class code assignments |
| Property | Dec pages, policy docs, appraisal docs |
| BOP | Dec pages, policy docs |
| Umbrella-Excess | Dec pages, underlying limits schedules |
| Professional-Liability | E&O policy docs, applications |
| Cyber | Policy docs, applications |
| COIs | Certificates of insurance (incoming and outgoing) |
| Applications | Submitted applications and quotes (all LOBs) |
| Audits | Premium audit docs, payroll reports, audit worksheets |
| Loss-Runs | Loss run reports by carrier and year |
| Renewals | Renewal packets, quote comparisons, correspondence by year |
| Correspondence | Emails, letters, notes sorted by date |
| Billing | Invoices, payment confirmations, financing agreements |
| Claims | Claim docs, adjuster correspondence, settlement info |
