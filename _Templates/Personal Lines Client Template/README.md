# Personal Lines Client Folder Template

Copy this entire folder for each new personal lines client. Rename to `[Client Last Name], [First Name]`.

## Folder Guide

| Folder | What goes here |
|---|---|
| Auto | Dec pages, ID cards, policy docs, endorsements |
| Home-Property | Dec pages, policy docs, appraisals, inspection reports |
| Umbrella | Dec pages, policy docs |
| Life | Policy docs, applications, beneficiary forms |
| Health-Medicare | Plan docs, enrollment forms, ANOC, provider directories |
| Other-Coverage | Boat, RV, motorcycle, valuables, flood, etc. |
| Applications | Submitted applications and quotes (all LOBs) |
| Renewals | Renewal packets and correspondence by year |
| Correspondence | Emails, letters, notes sorted by date |
| Billing | Invoices, payment confirmations, EFT docs |
| Claims | Claim docs, adjuster correspondence, settlement info |
